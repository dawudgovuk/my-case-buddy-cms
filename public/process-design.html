1

Onboarding & Verification

Every user registers with a specified role (LIP, McKenzie Friend, Solicitor, Barrister). Strapi enforces email confirmation using HMAC-SHA256 signed links before critical actions can be taken.

  • Single source of truth in up_users
  • 10-minute short-lived JWT for high security
  • HttpOnly rotation cookie (strapi_up_refresh)
2

Legal Roadmap GPS

LIPs avoid procedural panic by following a 5-tier guidance tree. Common requirements like MIAM mediation, fee remission (EX160), and Cafcass interviews are dynamically organized into ordered journeys.

  • Guidance Maps ➔ Journeys ➔ Steps
  • Conditional branching (C1A harm thresholds)
  • Directly attached to active case tracker
3

Case Workspace Hub

All sensitive family court entities are strictly scoped to the parent case. Parties, hearings, court orders, documents, and append-only case notes cannot be manipulated out-of-context.

  • Strict FPR cross-tenant data isolation
  • Append-only timestamped notes audit log
  • HTTP(S) validated document links

🔐 Authentication, Identity & Session Security

Strapi users-permissions operates as the single source of truth. Security mechanisms include cryptographic HMAC-SHA256 email verification, short-lived JWTs (10 min), HttpOnly refresh cookies, and strict absence of browser localStorage secrets.

✓

Zero LocalStorage Leaks

Sensitive family court records, child identities, and case notes are strictly held in memory. Refresh cookies are marked HttpOnly and cannot be accessed via XSS.

⚡

Self-Healing Neon Auth

If an older account exists only in Neon Auth (Better Auth), sign-in automatically provisions a corresponding Strapi account on-the-fly, synchronizing credentials.

🛡️

FPR Role Authorization

Verified legal professionals (McKenzie Friends, Solicitors, Barristers) undergo email confirmation checks before they are permitted to browse open case support requests.

💡

Conditional Step Evaluation

Not all legal steps apply to all families. When a litigant indicates domestic abuse concerns, the engine dynamically activates Step 2.2 (Form C1A) and references Practice Direction 12J. If the child's address is withheld, Form C4 is flagged.

📌

Embedded Case Roadmap Tracker

The guidance engine isn't a static wiki — it embeds directly into the active case view (CaseOverviewTab.tsx and LegalHubTab.tsx). Users can tick off completed milestones and share progress with their McKenzie Friend.

🤝 Peer Collaboration & Family Court Confidentiality

Under the UK Family Procedure Rules (FPR Section 12), proceedings involving children are strictly confidential. My Case Buddy implements cryptographic isolation, redacted previews, and atomic joining safeguards.

⚡

Pooled vs Direct DB

Neon provides PgBouncer connection pooling for sub-millisecond web API queries, while direct unpooled endpoints are strictly used for DDL migrations to avoid transaction lock failures.

📦

Dual Verification Gate

Both projects enforce strict zero-regression TypeScript checks:

  • CMS: npm run lint && npm run build
  • API: npm run build && npm test
🔒

Mandatory Migrations

Zero ad-hoc live schema edits. Every change to columns, enums, or link tables requires versioned Knex migrations in database/migrations/ with both up() and down().
